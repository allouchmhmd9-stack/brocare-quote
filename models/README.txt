Text-reading model used by paddle-rec.js

  arabic_PP-OCRv5_mobile_rec.onnx   PaddleOCR PP-OCRv5 Arabic recognition model, ONNX build
  arabic_PP-OCRv5_mobile_rec.yml    its configuration (the character list is copied to the .dict.json)
  arabic_PP-OCRv5_mobile_rec.dict.json   the model's 747 characters, in order (includes ٠١٢٣٤٥٦٧٨٩)
